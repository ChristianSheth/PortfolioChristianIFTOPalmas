Minha experiência com Git e GitHub

Durante a realização desta atividade, tive meu primeiro contato prático com a ferramenta de controle de versão Git.

Inicialmente, precisei instalar o Git no Windows e aprender a utilizar seus comandos básicos. Uma das dificuldades encontradas foi configurar o ambiente e entender como conectar o computador ao GitHub.

Após a instalação, aprendi a clonar um repositório, modificar arquivos, registrar alterações utilizando commits e enviá-las para o repositório remoto através do comando git push.

Essa experiência foi importante para compreender como equipes de desenvolvimento conseguem trabalhar no mesmo projeto de forma organizada e segura.
