📖 DOCUMENTAÇÃO DAS TAGS HTML


🎵 Tag <audio>

A tag <audio> é utilizada para inserir arquivos de áudio em uma página HTML. Ela permite que o usuário reproduza, pause e controle a mídia diretamente pelo navegador.

Atributos principais:

  • controls: exibe os botões de reprodução, pausa e volume.
  • autoplay: inicia o áudio automaticamente ao abrir a página.
  • loop: repete o áudio continuamente.
  • muted: inicia o áudio sem som.
  • preload: define como o navegador deve carregar o áudio.

Exemplo:

<audio controls> <source src="musica.mp3" type="audio/mpeg"> </audio>

🎥 Tag <video>

A tag <video> é utilizada para inserir vídeos em páginas HTML. Ela permite reproduzir arquivos de vídeo diretamente pelo navegador sem a necessidade de programas externos.

Atributos principais:

  • controls: exibe os controles do vídeo.
  • width: define a largura do vídeo.
  • height: define a altura do vídeo.
  • autoplay: inicia o vídeo automaticamente.
  • loop: repete o vídeo continuamente.
  • muted: inicia o vídeo sem som.
  • poster: exibe uma imagem de capa antes da reprodução.
  • preload: define como o navegador deve carregar o vídeo.

Exemplo:

<video width="560" controls> <source src="video.mp4" type="video/mp4"> </video>

📝 Conclusão

As tags <audio> e <video> são importantes para a criação de páginas multimídia, pois permitem incorporar sons e vídeos de forma simples e interativa. Esses recursos tornam os sites mais dinâmicos e melhoram a experiência do usuário.
